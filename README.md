# لعبة «فتّشها» (Fatteshha) - تحداك في كل كلمة 🇰🇼

لعبة إلكترونية عربية متكاملة للبحث عن الكلمات المخفية داخل شبكات الحروف، مبنية من الصفر بهوية شبابية كويتية عصرية، تدعم اللعب الفردي، واللعب المحلي الجماعي، ومباريات الأونلاين المباشرة عبر الإنترنت، بالإضافة إلى وضع مخصص لأجهزة Android TV.

---

## 🌟 مميزات اللعبة

### 1. أوضاع اللعب المتعددة
- **اللعب الفردي (Solo Play)**:
  - 9 تصنيفات مختلفة (تراث كويتي، أمثال ومصطلحات، أكلات كويتية، حيوانات وبيئة، جغرافيا، علوم وفضاء، إسلاميات، رياضة، تكنولوجيا).
  - 50 مرحلة لكل تصنيف (إجمالي 450 مرحلة متدرجة الصعوبة).
  - شبكات 8×8 (المراحل 1–10)، 10×10 (المراحل 11–30)، 12×12 (المراحل 31–50).
  - نظام التلميحات الذكية لكشف أطراف الخيط.
  - احتساب النجوم، الوقت، ونقاط الخبرة XP.
- **اللعب المحلي (Local Party Mode)**:
  - تنافس 2 إلى 4 لاعبين على نفس الجهاز أو شاشة التلفزيون.
  - تحديد الكلمات بألوان خاصة لكل متنافس مع لوحة نتائج حية.
  - إعلان الفائز عند نهاية الجولة مع احتفالات كويتية.
- **اللعب أونلاين (Real-time Multiplayer)**:
  - مباريات مباشرة في الوقت الفعلي عبر تقنية WebSockets.
  - إنشاء غرفة برمز كود فريد (مثل `KWT77`).
  - مزامنة فورية للكلمات المكتشفة ومنع اكتشاف الكلمة نفسها مرتين.
  - نظام ردود كويتية فورية («كفووو»، «يا وحش»، «جبتها قبلك»).
  - كشف انقطاع الاتصال وإعلان الفائز بالنقاط.

### 2. محرك البحث عن الكلمات
- توليد شبكات الحروف العربية ديناميكياً مع دعم 8 اتجاهات (أفقياً، رأسياً، قطرياً).
- توزيع عشوائي متوازن للحروف العربية المتبقية.
- دعم السحب باللمس على الهواتف والأجهزة اللوحية، والنقر بالماوس، والتحكم بالريموت كنترول.
- تطبيع الحروف العربية (إزالة التشكيل، همزات الألف، والتاء المربوطة).

### 3. دعم أجهزة Android TV
- وضع مخصص للتلفزيون مع واجهة مناسبة لمسافة المشاهدة.
- تحكم كامل بالريموت وأزرار الأسهم (D-Pad).
- زر `OK / Enter` لبدء واكتمال تحديد الكلمة بدون شاشة لمس.
- مؤشر تركيز مرئي ومكبر مع مؤثرات صوتية لكل حركة.

### 4. الحسابات والملفات والأوسمة
- دعم عدة ملفات لاعبين على نفس الجهاز وتبديل الملف النشط بسهولة.
- حسابات مستخدمين مع حفظ التقدم في قاعدة البيانات.
- مستويات اللاعبين، رصيد العملات، ونقاط الخبرة XP.
- 10 أوسمة وإنجازات كويتية كشخة («صقر الكويت»، «فاتح الأبواب»، «ملك الدواوين»).
- لوحة الشرف والمتصدرين العالمية.

### 5. المؤثرات الصوتية والهوية
- مؤثرات صوتية مُولّدة برمجياً باستخدام Web Audio API (تعمل بدون إنترنت وبدون ملفات صوتية خارجية مكسورة).
- تعليقات ورسائل تشجيعية باللهجة الكويتية الحماسية.

## 🚀 طريقة التشغيل السريع

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm أو pnpm

### خطوات التشغيل
1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```

2. تشغيل خادم التطوير المدمج (Express + Vite + WebSockets):
   ```bash
   npm run dev
   ```

3. افتح المتصفح على:
   ```
   http://localhost:3000
   ```

## 🛠️ البنية البرمجية

- **الواجهة الأمامية**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti.
- **الخادم والخلفية**: Node.js, Express, WebSocket (`ws`).
- **المحرك**: خوارزميات توليد وتوزيع الكلمات والتحقق الهندسي للمسارات.
- **قاعدة البيانات**: تخزين دائم مع دعم التصدير لـ Cloudflare D1 و SQLite.
